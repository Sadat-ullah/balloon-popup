# 🎈 Balloon Math Blast

An interactive, responsive math puzzle game designed for kids. Pop the floating water balloon with the correct answer, unlock levels winding up the Sky Map, and earn golden stars!

## 🚀 Features
- **100 Sky Map Levels**: Dynamic bottom-to-top Candy Crush-style progression map.
- **Water-Balloon Physics**: Jelly wobble, surface tension ripple, and water splash VFX on pop.
- **Audio & Haptics**: Procedural Web Audio API sound effects and background music.
- **Multi-Device Support**: Fully optimized for mobile screens (`375×812`) with safe-area sticky navigation, tablets, and desktop browsers.
- **Celebration Modal & Clues**: Friendly mascot reactions, animated star rewards, and visual dot math clues on retry.

## 🛠️ Tech Stack
- React 18
- TypeScript
- Vite
- Tailwind CSS
- Lucide React
- Canvas Confetti

## 💻 Local Development
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
